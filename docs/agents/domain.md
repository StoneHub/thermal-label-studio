# Domain docs

Read the repository's domain language before exploring or changing source.

## Sources

- `CONTEXT.md` is the glossary and contains no implementation details.
- `docs/adr/` contains decisions that were hard to reverse, surprising without context, and made after a real tradeoff.

If either path is absent, continue without creating an empty placeholder. Add a glossary term when its meaning is resolved. Add an ADR only when all three decision criteria apply.

Use the glossary's exact terms in issues, source, tests, and architecture reports. Flag a proposed change that contradicts an ADR.
