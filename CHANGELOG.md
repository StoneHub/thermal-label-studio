# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-03-03

### Added

- React + Konva label editor with multi-layer canvas support (text, shape, image).
- Transform tooling (move/resize/rotate), snap guides, optional grid, z-order controls.
- Undo/redo and keyboard shortcut system.
- Template browser with starter packs and local save flow.
- Image upload pipeline with reusable local image library.
- Clipboard image paste support for fast composition.
- API endpoints for health, templates, render, and print-job orchestration.
- Shared core package with layer/template helpers and reducer tests.

### Improved

- Larger controls and stronger visual hierarchy for better usability.
- Mobile layout and desktop workflow parity.

### Notes

- Print pipeline is currently orchestration-first; real device execution hardening is next.
